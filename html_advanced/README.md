# HTML - Advanced

This directory contains HTML exercises focused on structuring web pages using HTML5 elements and semantic markup.

## Topics

- HTML5 document structure
- HTML elements and attributes
- Semantic HTML
- Headings and paragraphs
- Lists and tables
- Links and navigation
- Images and SVG
- Audio and video
- Blockquotes and quotations
- Forms of embedded content using `iframe`
- HTML accessibility and W3C validation
